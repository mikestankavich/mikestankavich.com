## Project Overview

This is a personal branding site for Mike Stankavich built with Astro.js. The project combines a resume/CV site with a blog platform, featuring both a tailored resume section and a content management system for blog posts.

## Key Commands

### Development

- **Start development server**: `pnpm run dev` (runs Astro type checking with watch and dev server)
- **Simple start**: `pnpm start` (runs Astro dev server only)
- **Build the site**: `pnpm run build` (runs type checking and builds the site)
- **Preview the build**: `pnpm run preview` (previews the built site)
- **Lint and format code**: `pnpm run lint` (runs Prettier and ESLint)

### Resume Generation

- **Generate PDF resume**: `pnpm run pdfresume` (converts Markdown resume to PDF)
  - This uses the `md-to-pdf` package to convert Markdown files from the `resume/` directory to PDF files in the `public/` directory
  - Multiple resume variants are supported with different filenames

## Architecture

### Core Structure

1. **Resume/CV Site**: 
   - Main content source is `src/data.yaml` which contains all personal information including skills, work history, etc.
   - Resume section is built using Astro components that consume this YAML data

2. **Blog Platform**:
   - Content lives in `src/content/post/` as Markdown files
   - Content schema is defined in `src/content/config.ts`
   - Supports tags, pagination, and other blog features

3. **Resume PDF Generation**:
   - Markdown resume files in `resume/` directory
   - Custom CSS for PDF formatting in `resume/resume-style.css`
   - PDF conversion script `resume/resume-md-to-pdf.js`
   - Generated PDFs are stored in `public/` for download from the site

### Key Files and Directories

- `src/data.yaml`: Primary data source for the resume/CV
- `src/site.config.ts`: Site-wide configuration including metadata
- `src/components/`: Reusable Astro components 
  - `cv/`: Resume-specific components
  - `blog/`: Blog-specific components
  - `layout/`: Layout components (header, footer)
- `src/pages/`: Page templates and routes
- `src/content/`: Content collection for blog posts
- `resume/`: Markdown resume files and PDF generation tooling

## Customization

1. **Site Information**: Edit `src/site.config.ts` to modify site title, description, etc.
2. **Resume Data**: Edit `src/data.yaml` to update resume content
3. **Blog Posts**: Add Markdown files to `src/content/post/`
4. **Theming**: Modify `src/styles/app.css` for theme colors and styling

## Deployment

The site is configured for static site generation and can be deployed to various platforms:

- Vercel deployment is pre-configured (analytics included)
- For other platforms, use the `dist/` directory generated by `pnpm run build`

## Notes

- The project uses PNPM (`packageManager: "pnpm@8.x.x"`) for package management
- Tailwind CSS is used for styling
- The site supports both light and dark themes
- The site includes RSS feed generation
